Claude Desktop MCP Server Config Guide & Setup

How to configure local and remote Model Context Protocol (MCP) servers in Claude Desktop on macOS and Linux.

Configuration File Location

Claude Desktop reads its tool definitions from a JSON file located at:

  • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Linux: ~/.config/Claude/claude_desktop_config.json

Zero-Install uvx Configuration

Using Astral's uvx utility, Claude Desktop can invoke MCP servers directly from PyPI without requiring manual cloning or virtual environment setup:

{
  "mcpServers": {
    "crawlengine": {
      "command": "uvx",
      "args": ["crawlengine-mcp"]
    },
    "pgsafe": {
      "command": "uvx",
      "args": ["pgsafe-mcp"]
    }
  }
}
